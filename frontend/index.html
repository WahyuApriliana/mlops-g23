Tentang Program Studi
Sistem Informasi

Program Studi Sistem Informasi mempelajari penerapan teknologi informasi untuk mendukung kebutuhan bisnis dan organisasi. Mahasiswa dibekali kemampuan dalam analisis sistem, pengembangan aplikasi, pengelolaan data, serta pemanfaatan teknologi informasi.
